# 05 ファイル読取の既定配送量と継続

Status: ready-for-agent
Resolution: implemented

Spec: [採用9項目の仕様](../spec.md)

## 現状と目的

src/files.rsはmax_lines省略時usize::MAXを使用し、既定メッセージ設定では約1MiBまで本文を返す。

## 作業範囲

- 初期候補を200行・64KiBとし、任意max_bytesを既存の信頼された配送上限内で指定可能にする。
- next_line/has_moreと元本文・改行を維持する。ソースファイル全体を制限しない。
- 1行が返却予算を超える場合を明示し、黙った本文欠落や文字化けを避ける。

## 受入条件

- [x] 省略時、大きな指定、小さすぎる指定、空ファイル、終端、長大行、CRLF/日本語を検証する。
- [x] 範囲外の長大行・不正UTF-8で、要求範囲の読取を失敗させない。
- [x] 明示的に増やした配送量でも信頼されたメッセージ上限を超えず、継続で目的範囲を取得できる。

## 依存と検証

01〜04を基礎にし、06とbyte予算の説明を揃える。

tests/contracts.rs、tests/transport.rs、tests/real_app_server.pyの大ファイル・行範囲ケース。初期値の転送量を比較記録する。
