# 公式診断の本文保存を専用領域へ分離する

2026-10-23の設計第5ラウンドQ16で採用。公式実行基盤を独自改変せず利用するため、local-mcp自身の本文・入出力・受付記録の非永続化とは別に、App Serverの診断へ本文が残り得ることを例外として認める。
公式診断は利用者の通常Codexの保存先から分離して場所を表示し、不要な外部送信を無効にし、通常終了と元App Serverの終了を確認した後に専用の管理領域を削除する。
異常終了で残留した場合は場所を案内し、終了を推測した削除や他用途の保存先の削除は行わず、`history.persistence=none`等を全診断の本文非保存保証とは説明しない。

根拠: 本人の「Q13, Q16: 推奨どおり。」という本案件での回答、[公式Config Reference](https://learn.chatgpt.com/docs/config-file/config-reference)。旧製品での例外合意の流用ではない。
